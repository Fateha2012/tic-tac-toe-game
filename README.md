# Tic Tac Toe

A tic-tac-toe (O/X) game built with HTML, CSS and JavaScript for learning.

🔗 **Live demo:** https://fateha2012.github.io/tic-tac-toe-game/

## Features

- Two players take turns placing O and X
- Reset button to start a new game

## Built With

- HTML5
- CSS3
- JavaScript

## Run Locally

Open `index.html` in your browser.
